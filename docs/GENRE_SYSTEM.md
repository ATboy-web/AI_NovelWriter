`lifecycle_ui.py` 净减 **357 行**。

## 二、三层结构

```
app/genres_data.py    ← 纯数据：CHANNEL_LABELS / BUILTIN_GENRES / BUILTIN_TAGS
        ↓
app/genres.py         ← 逻辑：GenreRegistry（读取/校验/增删/持久化）+ GenreResult
        ↓
app/lifecycle_ui.py   ← UI：只读注册表 + 「管理题材…」按钮
```

> ❗ **数据只有一处**。有守卫测试拦"把清单搬回 UI"（`TestDataLivesInOnePlace`），
> 因为本仓已因「同一事实写两处」踩过 5 次。

## 三、题材的字符串约定

形如 `大类-子类`（`玄幻-东方玄幻`）。**自定义题材允许不含 `-`**
（用户可以只写 "蒸汽朋克"，此时整串即大类）。

统一走 `split_genre()` / `make_genre()` —— 别在别处手写 `split("-")`。

## 四、配置文件

**唯一来源**：`app/genres.py::default_genres_file()`
= `~/.ai_novel_writer/genres.json`

```json
{
  "custom_genres":  {"male": ["蒸汽朋克", "硬科幻-太空歌剧"], "female": []},
  "custom_tags":    {"male": {"世界观": ["蒸汽动力", "飞空艇"]}},
  "removed_genres": {"male": ["玄幻-宗门林立"]}
}
```

| 字段 | 含义 |
|---|---|
| `custom_genres` | 用户自己加的题材（追加在内置之后） |
| `custom_tags` | 用户自己加的标签（**追加**到分类里，不清空内置标签） |
| `removed_genres` | 被**隐藏**的内置题材。配置只表达"我不想看到它"，源码里的清单是事实 |

### 宽松读、严格写

- **读**：文件不存在 / JSON 损坏 / 顶层不是对象 / 字段形状不对 ⇒ **一律忽略并降级为内置清单**，绝不抛。
  （题材选择不该让应用起不来。）
  ❗ 这里的 `isinstance` 检查不能偷懒用 `or {}` 兜底 —— 字段是非空**列表**时
  `x or {}` 会原样返回列表，后面 `.items()` 直接抛。实测踩到过。
- **写**：校验 + 去重 + **原子替换**（唯一临时名 + `os.replace`）。

## 五、界面操作

新建小说对话框 → 「小说类型」右侧「**管理题材…**」：

- 直接在**最终清单**上增删（用户的心智模型是"我要的列表长这样"，不是"维护一份补丁"）
- 保存时求**差集**回写：新增项 → `add_genre`；消失项 → `remove_genre`
  （自定义题材被删掉；内置题材被隐藏）
- 所以"隐藏内置题材"不需要另一套界面 —— 它就是"删除"的自然语义

**已知取舍（不做虚假承诺）**：`dialogs.edit_items` 支持上下移动，但**顺序不持久化**；
生效顺序恒为「内置（保持原位）→ 自定义（追加末尾）」。自定义排序要引入一份完整顺序表，
收益（微调下拉顺序）不值那份复杂度与漂移风险。

## 六、🔴 不破坏已有作品

`with_novel_genre(channel, genre)` 保证：**某本小说正在用的题材，即使已被用户删除/隐藏，
也仍然出现在选择器里**。

为什么这条是必须的：否则 `ttk.Combobox` 的值会变成"不在候选项里的字符串" ——
界面显示空白，用户一保存就把作品的题材**静默改掉**了。

### 两处判据为什么是"上界"而不是"一条都不许"

`TEMPLATES`（内置故事模板）会写 `{"genre": "玄幻-异世大陆"}` 这类**默认值** ——
那是模板字段默认，不是题材目录。实测 `系统流` 既在标签目录里、**也是**一个模板名。

所以判据取"明显低于目录规模的上界"（题材 < 10 / 标签 < 5）：
目录被搬回来时立刻变红，而加模板不会误报。

## 八、本轮顺手修掉的真缺陷

1. **`add_genre` 的判序错误**：先查"是否内置"再查"是否曾被隐藏" ⇒ 恢复隐藏项会命中
   `already_builtin` 被拒绝，界面承诺的"再次添加同名即可恢复"变成空话。
   改成先查隐藏（实测踩到）。
2. **`_load` 用 `or {}` 兜底**：字段是非空列表时 `.items()` 抛异常，
   违反"绝不抛"的契约。改为显式 `isinstance`。
3. **`writing_skills_panel` 静默回落默认题材**：读不到 meta 时把题材换成
   `玄幻-东方玄幻` 且无任何提示 —— 用户的自定义题材会被悄悄换掉。已加日志。
