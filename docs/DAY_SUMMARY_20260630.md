**🔴 阻塞问题（5个）**：

| # | 问题 | 文件 | 影响 |

| 3 | 路径遍历漏洞 | reading_manager.py:71-83 | 任意文件读取/覆盖 |
| 4 | 解密失败返回明文 | secure_config.py:56-60 | API Key泄露风险 |
| 5 | 双配置系统导致明文存储 | config.py | API Key明文存储 |

**🟡 建议改进（7个）**：

| # | 问题 | 文件 |
|---|------|------|
| 1 | Token统计错误（字符数≠token数） | ai_client.py:536 |
| 2 | 模型降级路由错误 | ai_client.py:568-591 |
| 3 | 异常吞掉（50+处） | novel_agent.py |
| 4 | 关键词提取O(n³)性能差 | memory_manager.py:700-710 |
| 5 | print替代日志系统 | ai_client.py:783-787 |
| 6 | 重复导入re模块 | novel_agent.py |
| 7 | 文件超1800行职责过重 | novel_agent.py |

### 2.3 修复结果

**所有5个阻塞问题已修复**：
1. ✅ `_diag`未定义 → 导入diagnostic_logger + 添加保护检查
2. ✅ 缺乏线程安全 → 添加threading.Lock
3. ✅ 路径遍历漏洞 → 添加路径安全检查
4. ✅ 解密回退泄露 → 检测Fernet token格式
5. ✅ 双配置系统 → AppConfig集成SecureConfig

**所有7个建议改进已修复**：
1. ✅ Token统计错误 → 使用×1.5系数估算
2. ✅ 降级路由错误 → 重新检测provider
3. ✅ 异常吞掉 → 5处改为记录日志
4. ✅ 关键词提取性能 → 集合去重优化
5. ✅ print替代日志 → 改用诊断日志系统
6. ✅ 重复导入 → 统一使用顶部import
